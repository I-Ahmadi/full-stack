# Node JS

This folder follows the same learning style as `1-JavaScript`: numbered topic folders with focused lesson files inside each folder.

## Learning Order

0. `0-setup-reference` - VS Code setup and theory notes
1. `1-basics` - Node fundamentals, globals, process, path, os
2. `2-modules` - CommonJS, ES modules, exports, imports, module resolution, caching
3. `3-file-system` - fs module, sync/async files, callbacks, promises, path-safe file access
4. `4-npm-packages` - npm, package.json, dependencies, dev dependencies, scripts
5. `5-http-server-routing` - core HTTP server, routes, methods, URL/query parsing, status codes, headers
6. `6-events-event-loop` - EventEmitter, timers, event loop phases, event-driven architecture
7. `7-streams-buffers` - buffers, readable streams, writable streams, piping
8. `8-async-promises` - callbacks, promises, async/await, async HTTP examples
9. `9-runtime-tools` - CLI args, environment variables, debugging, child processes, worker threads
10. `10-node-farm` - Node Farm project with core Node modules, templates, files, and npm packages
11. `11-natours` - Natours course checkpoints for Node, Express, MongoDB, and Mongoose
