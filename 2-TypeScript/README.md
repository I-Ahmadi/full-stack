# TypeScript

This folder follows the same learning style as `1-JavaScript`: numbered topic folders with small lesson files inside each folder.

## Learning Order

1. `1-basics` - TypeScript purpose, static checking, compile/run workflow
2. `2-data-types` - primitive types, special types, null and undefined
3. `3-type-annotations` - inference, annotations, assertions
4. `4-arrays-tuples-enums` - arrays, tuples, enums
5. `5-objects` - object shapes, optional/readonly props, index signatures
6. `6-statements-narrowing` - unions, literals, narrowing, discriminated unions
7. `7-functions` - function types, callbacks, overloads
8. `8-interfaces-types` - interfaces, aliases, intersections, utility types
9. `9-classes-oop` - classes, inheritance, access modifiers, abstract classes
10. `10-generics` - generic functions, interfaces, constraints, keyof/typeof
11. `11-modules-config` - modules, tsconfig, declaration files, npm scripts
12. `12-async-api` - promises, API data, async error handling
13. `13-project` - small TypeScript project structure
