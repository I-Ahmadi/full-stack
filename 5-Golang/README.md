# Golang

This folder follows the same learning style as `1-JavaScript`: numbered topic folders with focused lesson files inside each folder.

## Learning Order

1. `1-basics` - Go setup, packages, main function, variables, constants
2. `2-data-types` - basic types, zero values, conversions
3. `3-operators` - arithmetic, comparison, logical operators
4. `4-control-flow` - if, switch, for loops, defer
5. `5-arrays-slices-maps` - arrays, slices, maps, ranges
6. `6-functions` - parameters, returns, variadic functions, closures
7. `7-structs-interfaces` - structs, composition, interfaces
8. `8-pointers-methods` - pointers, methods, value vs pointer receivers
9. `9-errors` - errors, wrapping, panic and recover
10. `10-packages-modules` - packages, imports, go.mod, visibility
11. `11-concurrency` - goroutines, channels, select, sync tools
12. `12-files-json-http` - files, JSON, HTTP clients and servers
13. `13-testing` - unit tests, table tests, benchmarks
14. `14-project` - small Go project structure
